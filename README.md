# 수어 인식 프로토타입

로컬 실행 주소: http://localhost:5173/

브라우저에서 손모양, 양어깨 대비 손 위치, 입모양을 저장하고 비교하는 실험용 프로그램입니다. MediaPipe가 어깨·팔꿈치·손목·손가락과 입 모양 블렌드셰이프를 추적하고, 사람형 3D 아바타가 팔과 손을 따라 합니다. 팔은 Pose Landmarker Heavy GPU, 입모양은 약 7fps, 3D 아바타는 약 20fps로 갱신합니다. 영상은 서버에 업로드하지 않으며, 모델과 라이브러리를 처음 불러올 때 인터넷 연결이 필요합니다.

## 사용

1. 카메라를 시작하고 브라우저의 카메라 권한을 허용합니다.
2. 얼굴의 입, 양어깨, 손을 함께 보여 주세요. 정지 수어는 `샘플 저장`으로 같은 손모양·어깨 대비 위치·입모양을 3개 이상 저장합니다. 빠른 동작 수어는 `2초 동작 수집`으로 같은 동작을 3회 이상 저장합니다.
3. 손모양을 유지하면 비교 결과가 표시됩니다. 후보가 비슷하거나 저장된 샘플과 차이가 크면 판단을 보류합니다.
4. 백업 저장으로 JSON 파일을 내려받습니다. 백업 불러오기는 기존 데이터에 병합하며, 같은 백업을 다시 읽어도 중복 개수가 늘어나지 않습니다.
5. 저장·삭제·불러오기 직후의 변경은 `되돌리기`로 한 번 취소할 수 있습니다. 새로고침하면 되돌리기 기록은 사라집니다.
6. 정지 수어 분류를 사용하려면 수어 단어 이미지로 학습한 `YOLO11-cls` 모델을 ONNX로 내보내고, 클래스 순서가 같은 라벨 `.txt` 또는 `.json` 파일을 선택해 `모델 연결`을 누릅니다. 모델은 브라우저 메모리에서만 실행됩니다.

카메라 중지, 탭을 벗어나는 동작, 카메라 연결 종료 시 수집 중인 미완성 샘플은 버립니다. 샘플은 브라우저의 localStorage에 저장되므로 브라우저 데이터 삭제 전에 백업해 주세요. 기존 배열 형태의 샘플도 호환됩니다.

양어깨나 입모양이 사라지면 예측과 새 샘플 수집을 일시 보류합니다. 팔 관절이 잘려 있거나 가려지면 아바타는 손 위치만 따라갑니다. 기존 126개 값 손모양 샘플과 130개 값 어깨 기준 샘플은 보존·백업되지만, 입모양을 포함한 새 인식에는 사용하지 않습니다. 단어별로 다시 저장해야 합니다. 새 정지 샘플은 136개 값(손모양 126개 + 두 손목의 어깨 상대 좌표 4개 + 입모양 6개)이며, 입모양은 턱 벌어짐, 입 다물기, 오므림, 입술 내밀기, 좌우 웃음 값입니다. 동작 샘플은 2초 동안 수집한 프레임 시퀀스를 DTW로 비교합니다. 백업 버전은 3입니다.

## 범위

- 문장 번역이나 한국수어 사전 모델이 아닙니다. 입모양 값은 학습하지만 눈썹·시선·몸통 회전 같은 모든 비수지 신호는 아직 학습하지 않습니다.
- 표시되는 샘플 유사도는 정확도나 보정된 확률이 아닙니다. 거리 기준과 350ms 유지 시간은 초기 휴리스틱이며 실제 사용자 데이터로 평가해야 합니다.
- 좌우 손 감지 순서가 바뀌어도 손모양과 위치를 함께 대응해 비교합니다. 양어깨 중심과 어깨 폭을 기준으로 손의 좌우·상하 위치를 사용합니다.
- 아바타의 팔은 실제 어깨·팔꿈치·손목 관절을 따라 표현합니다. 얼굴 표정과 몸통 회전은 추적하지 않습니다.
- 동작 수집은 최대 32개의 랜드마크 프레임을 저장합니다. 이 시퀀스는 나중에 LSTM·Transformer 학습 데이터로 내보낼 수 있습니다.
- 기본 YOLO11 일반 물체 모델은 수어 단어를 분류할 수 없습니다. 이 앱은 수어 데이터로 학습한 분류 모델만 연결합니다. 감지용 YOLO11 모델은 입력·출력 형식이 달라 지원하지 않습니다.
- YOLO11은 손목 움직임이 0.4초 동안 작을 때만 실행됩니다. 손이 이동하는 수어는 기존의 관절 기반 비교 경로로 처리해야 합니다.

## YOLO11 모델 준비

학습 폴더는 클래스별로 나눕니다. 예: `dataset/train/안녕하세요/*.jpg`, `dataset/val/안녕하세요/*.jpg`. 각 클래스에는 다른 사람, 거리, 배경, 조명에서 찍은 정지 프레임을 포함해야 합니다. 학습 뒤에는 다음처럼 분류 모델을 ONNX로 내보냅니다.

```sh
yolo classify train model=yolo11n-cls.pt data=dataset epochs=50 imgsz=224
yolo export model=runs/classify/train/weights/best.pt format=onnx imgsz=224
```

라벨 파일은 모델 클래스 인덱스 순서대로 한 줄에 하나씩 씁니다.

```text
안녕하세요
감사합니다
사랑
```

Ultralytics의 학습 결과 `names` 순서와 라벨 파일 순서가 반드시 같아야 합니다. 128MB보다 큰 ONNX 파일은 브라우저에서 로드하지 않습니다.

## 검증

Node.js 24에서 별도 패키지 설치 없이 실행:

```sh
npm test
```

인식 기준, 양손 순서, 예측 안정화, 저장 데이터 검증, 카메라 거부 후 재시도, 수집 취소, 백업 병합, 저장 공간 부족을 검증합니다. 카메라 수명 주기 테스트는 모의 장치를 사용하며 실제 웹캠 인식률을 측정하지 않습니다.

손 추적 API 참고: [MediaPipe Hand Landmarker 공식 문서](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/web_js).
팔 관절 API 참고: [MediaPipe Pose Landmarker 공식 문서](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/web_js).
입모양 API 참고: [MediaPipe Face Landmarker 공식 문서](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker/web_js).

## Windows 데스크톱 앱

`desktop_app.py`는 Chrome 없이 카메라를 직접 여는 PySide6 실험용 데스크톱 앱입니다. MediaPipe Holistic의 Heavy 설정으로 팔·손·입 윤곽을 표시합니다. 실행 파일은 `release/SignLanguageDesktop/SignLanguageDesktop.exe`이며, `_internal` 폴더와 함께 유지해야 합니다.

개발 중에는 다음 명령으로 실행합니다.

```sh
python desktop_app.py
```

다시 EXE를 만들 때는 Windows에서 `build_desktop.bat`를 실행합니다. PySide6, OpenCV, MediaPipe, PyInstaller가 설치되어 있어야 합니다.
