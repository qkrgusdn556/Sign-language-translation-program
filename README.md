# 수어 인식 프로토타입

웹캠 영상에서 MediaPipe로 관절 좌표를 추출하고, 등록한 수어 동작을 비교해 단어와 문장으로 표시하는 실험용 프로젝트입니다. 기존 DTW 사이트와 별도 TCN 실험 사이트를 개발했습니다. 한국수어 전체를 번역하는 완성된 통역 시스템은 아닙니다.

## 프로젝트 구성

| 구성 | 역할 | 저장소 포함 여부 |
| --- | --- | --- |
| 기존 DTW 웹사이트 | 저장된 동작과 현재 동작의 시간 흐름을 맞춰 비교 | 이 저장소에 포함 |
| 별도 TCN 웹사이트 | 최근 관절 좌표 구간을 학습된 모델로 반복 분석 | 별도 로컬 프로젝트, 이 저장소에 소스 미포함 |
| 개인 샘플과 학습 모델 | 관절 좌표 JSON과 학습 체크포인트 | Git에서 제외 |

## 시스템 파이프라인

아래 그림은 두 사이트를 포함한 프로젝트 전체 구조입니다. 기존 사이트는 DTW를 사용하며, 인식 모드 선택과 TCN 추론은 별도 TCN 사이트에서 제공합니다. 3D 아바타는 이 인식 파이프라인에서 생략했습니다.

```mermaid
flowchart LR
    camera["카메라 입력"] --> tracking["MediaPipe 관절 추적<br/>손 · 어깨 · 팔"]
    tracking --> features["좌표 정규화<br/>130차원 특징"]
    features --> mode{"인식 모드 선택<br/>별도 TCN 사이트"}
    mode --> dtw["DTW<br/>저장 동작과 시간 정렬 · 비교"]
    mode --> tcn["TCN<br/>최근 구간 반복 분석"]
    dtw --> confirm["단어 후보 · 확정<br/>각 모드의 조건 확인"]
    tcn --> confirm
    confirm --> sentence["문장 조합 · 화면 표시<br/>단어 연결 · 규칙 기반 다듬기"]
    tcn -. "연결 · 추론 오류 시 DTW 전환" .-> dtw
    features --> collect["2초 동작 수집"]
    collect --> json[("컴퓨터 JSON 저장")]
    json -. "저장 샘플" .-> dtw
    json --> train["TCN 모델 학습<br/>Python · PyTorch"]
    train --> model[("학습 모델 .pt")]
    model -. "학습된 모델" .-> tcn
```

DTW와 TCN은 현재 **선택 모드**입니다. 동시에 점수를 합치는 방식이 아니며, TCN의 낮은 점수 후보를 DTW로 재검증하는 기능은 아직 구현하지 않았습니다. TCN 연결 또는 추론 오류가 발생하면 DTW 모드로 전환합니다.

## TCN 설명

TCN(Temporal Convolutional Network)은 여러 프레임에 걸친 움직임의 변화 패턴을 학습하는 시간 합성곱 신경망입니다. 이 프로젝트는 영상 자체가 아니라 손 관절과 어깨 기준 손목 위치로 만든 130차원 좌표 시퀀스를 입력합니다.

![TCN 실시간 수어 인식 흐름](docs/images/tcn-live-flow.png)

위 이미지는 AI 생성 설명용 개념도입니다. 사진의 자세는 실제 한국수어 동작이나 실험 결과를 증명하지 않습니다.

- 관측 프레임을 최소 75ms 간격으로 모으고, 최근 12~20프레임을 분석합니다.
- 추론 요청 간격은 최소 150ms이며 동시에 하나의 요청만 처리합니다. 실제 지연이 항상 150ms라는 뜻은 아닙니다.
- 후보 점수 85% 이상, 2위와 30%포인트 이상 차이, 같은 후보 300ms 유지 조건을 충족하면 단어를 출력합니다.
- 모델은 130차원 입력을 32채널로 변환하고 팽창률 1 · 2 · 4의 인과 잔차 블록 3개, 시간 평균, 단어 분류층을 사용합니다.
- 다음 단어를 분석하기 위해 DTW의 동작 종료 판정을 기다리지는 않습니다. 다만 자연스러운 연속 수어의 정확도와 지연은 별도 평가가 필요합니다.
- 현재 개별 단어 중심 학습만으로 연결 동작과 비수어 입력을 충분히 구분한다고 보장할 수 없습니다. 실제 연결 동작과 비수어 데이터 수집이 다음 과제입니다.

### DTW와 TCN의 역할

| 항목 | DTW | TCN |
| --- | --- | --- |
| 판단 방식 | 현재 동작과 저장 동작의 시간 흐름을 맞춰 거리 비교 | 학습된 시간 변화 패턴으로 단어 분류 |
| 신경망 사전 학습 | 불필요, 비교용 샘플 필요 | 이름이 붙은 동작 데이터로 학습 필요 |
| 새 단어 추가 | 샘플을 저장해 비교에 사용 | 새 데이터를 포함해 모델 재학습 |
| 현재 확정 방식 | 동작 종료 판정과 유사도 조건 | 최근 구간 반복 분석과 점수 · 유지 시간 조건 |
| 주요 한계 | 추적 누락과 잘못된 동작 구간에 취약 | 부족한 학습 데이터와 미학습 동작에 취약 |

샘플 유사도와 TCN 후보 점수는 실제 정확도가 아닙니다. 정확도는 학습에 사용하지 않은 새 촬영으로 평가해야 합니다. YOLO11 자음·모음 인식과 불확실한 TCN 후보의 DTW 재검증은 향후 계획입니다.

## 현재 DTW 인식 기준

한 손 누락 동작 비교의 확정 기준은 유사도 40% 이상입니다. 한 손이 보이는 동안에는 누락 시간·프레임 비율로 확정을 막지 않습니다. 아래 부분 비교의 0.12 거리 기준은 정지 비교에만 적용합니다. 후보 간 차이 조건은 유지합니다.

한 손 누락 보완: 손 개수가 다르면 남은 손을 저장된 두 손 중 가까운 쪽에 대응해 비교합니다. 손모양과 어깨 상대 위치를 함께 사용하며, 누락된 좌표는 생성하지 않습니다. 부분 점수는 최대 80%로 제한하며 정확도 확률이 아닙니다. 관측된 움직임이 3회 이상이고 같은 손 개수로 관측한 좌표 변화가 0.12 이상이어야 부분 동작을 확정할 수 있습니다. 손 개수가 바뀌는 것만으로 움직임이 있다고 판단하지 않습니다. 단어별 동작 샘플이 3개 이상이면 그 단어의 정지 샘플은 확정에 사용하지 않아 마지막 자세만 유지하는 것으로 동작 인식을 우회하지 못하게 합니다. 전체 인식 좌표가 사라지면 기존 220ms 보호 후 구간을 초기화합니다. 현재 사이트에만 적용했으며 TCN 모델은 변경하지 않았습니다.

복원 기준: 사용자가 제시한 2026-10-12 06:02 응답의 누락 보호·종료 판정 동작입니다. 보존된 수정본에서 이후 손 전용 변경을 되돌려 재구성했습니다. 220ms 이내 추적 누락 보호, 최근 3프레임 평균 움직임과 180ms 종료 판정, 복귀 직후 좌표 점프 무시, 동작 중 임시 유사도 및 비교 샘플 표시가 포함됩니다. 당시 파일 전체의 별도 스냅샷은 없으므로 바이트 단위 동일 복원을 주장하지 않습니다. 현재 컴퓨터 샘플 파일은 덮어쓰지 않았으며, 컴퓨터 저장과 64MB 불러오기는 유지합니다.

로컬 실행 주소: http://localhost:5173/

`run_web.bat` 또는 `python web_server.py --port 5173`으로 실행합니다. 샘플은 로컬 서버가 `data/sign-samples.json`에 자동 저장합니다. 직전 파일은 `data/sign-samples.json.bak`으로 보관됩니다. 단순 `http.server`로 실행하면 파일 저장 API가 없어 저장을 사용할 수 없습니다.

브라우저에서 손모양과 양어깨 대비 손 위치를 저장하고 비교하는 실험용 프로그램입니다. MediaPipe가 어깨·팔꿈치·손목·손가락을 추적하고, 사람형 3D 아바타가 팔과 손을 따라 합니다. 영상은 서버에 업로드하지 않으며, 모델과 라이브러리를 처음 불러올 때 인터넷 연결이 필요합니다.

## 사용

1. 카메라를 시작하고 브라우저의 카메라 권한을 허용합니다.
2. 양어깨와 손을 함께 보여 주세요. 정지 수어는 `샘플 저장`으로 같은 손모양·어깨 대비 위치를 3개 이상 저장합니다. 빠른 동작 수어는 `2초 동작 수집`으로 같은 동작을 3회 이상 저장합니다.
3. 손모양을 유지하면 비교 결과가 표시됩니다. 후보가 비슷하거나 저장된 샘플과 차이가 크면 판단을 보류합니다.
4. 백업 저장으로 JSON 파일을 내려받습니다. 백업 불러오기는 기존 데이터에 병합하며, 같은 백업을 다시 읽어도 중복 개수가 늘어나지 않습니다.
5. 저장·삭제·불러오기 직후의 변경은 `되돌리기`로 한 번 취소할 수 있습니다. 새로고침하면 되돌리기 기록은 사라집니다.
6. 정지 수어 분류를 사용하려면 수어 단어 이미지로 학습한 `YOLO11-cls` 모델을 ONNX로 내보내고, 클래스 순서가 같은 라벨 `.txt` 또는 `.json` 파일을 선택해 `모델 연결`을 누릅니다. 모델은 브라우저 메모리에서만 실행됩니다.

카메라 중지, 탭을 벗어나는 동작, 카메라 연결 종료 시 수집 중인 미완성 샘플은 버립니다. 첫 실행 시 컴퓨터 저장 파일이 없으면 기존 IndexedDB 또는 localStorage 샘플을 이전하며, 기존 브라우저 원본은 지우지 않습니다. 이후에는 컴퓨터 파일을 우선 읽고 저장합니다. 기존 배열 형태의 백업도 호환됩니다. 여러 탭에서 동시에 샘플을 변경하지 마세요.

양어깨가 사라지면 예측과 새 샘플 수집을 일시 보류합니다. 팔 관절이 잘려 있거나 가려지면 아바타는 손 위치만 따라갑니다. 기존 126개 값의 손모양 샘플은 보존·백업되지만 어깨 위치 정보가 없어 새 인식에는 사용하지 않습니다. 어깨 기준 샘플을 다시 저장해야 합니다. 새 정지 샘플은 130개 값(손모양 126개 + 두 손목의 어깨 상대 좌표 4개)이며, 동작 샘플은 2초 동안 수집한 프레임 시퀀스를 DTW로 비교합니다. 백업 버전은 3입니다.

## 범위

- 문장 번역이나 한국수어 사전 모델이 아닙니다. DTW는 동작 시퀀스를 비교하지만 신경망을 학습하지 않으며, 얼굴 표정과 입모양은 인식하지 않습니다.
- 표시되는 샘플 유사도는 정확도나 보정된 확률이 아닙니다. 거리 기준과 확정 시간은 휴리스틱이며 실제 사용자 데이터로 평가해야 합니다.
- 좌우 손 감지 순서가 바뀌어도 손모양과 위치를 함께 대응해 비교합니다. 양어깨 중심과 어깨 폭을 기준으로 손의 좌우·상하 위치를 사용합니다.
- 아바타의 팔은 실제 어깨·팔꿈치·손목 관절을 따라 표현합니다. 얼굴 표정과 몸통 회전은 추적하지 않습니다.
- 동작 수집은 최대 32개의 랜드마크 프레임을 저장합니다. 이 시퀀스는 별도 TCN 사이트에 백업으로 불러와 학습에 사용할 수 있습니다. 두 사이트의 샘플과 모델은 자동 공유하지 않습니다.
- 기본 YOLO11 일반 물체 모델은 수어 단어를 분류할 수 없습니다. 이 앱은 수어 데이터로 학습한 분류 모델만 연결합니다. 감지용 YOLO11 모델은 입력·출력 형식이 달라 지원하지 않습니다.
- YOLO11은 손목 움직임이 0.4초 동안 작을 때만 실행됩니다. 손이 이동하는 수어는 기존의 관절 기반 비교 경로로 처리해야 합니다.

## YOLO11 모델 준비

학습 폴더는 클래스별로 나눕니다. 예: `dataset/train/안녕하세요/*.jpg`, `dataset/val/안녕하세요/*.jpg`. 각 클래스에는 다른 사람, 거리, 배경, 조명에서 찍은 정지 프레임을 포함해야 합니다. 학습 뒤에는 다음처럼 분류 모델을 ONNX로 내보냅니다.

```sh
yolo classify train model=yolo11n-cls.pt data=dataset epochs=50 imgsz=224
yolo export model=runs/classify/train/weights/best.pt format=onnx imgsz=224
```

라벨 파일은 모델 클래스 인덱스 순서대로 한 줄에 하나씩 씁니다.

```text
안녕하세요
감사합니다
사랑
```

Ultralytics의 학습 결과 `names` 순서와 라벨 파일 순서가 반드시 같아야 합니다. 128MB보다 큰 ONNX 파일은 브라우저에서 로드하지 않습니다.
